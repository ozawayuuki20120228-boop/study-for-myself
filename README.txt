鴻鵠 2.0 - 公式書影対応版

GitHub Pagesへの配置：このフォルダ内のファイルをリポジトリのルートへアップロードしてください。

表紙画像：出版社公式サイトで確認できた書影画像を初期登録しています。青チャートなど一部の書籍は公式画像URLが未登録のため「電子版の表紙画像 未取得」と表示されます。出版社公式の書影は書籍版と電子版で同一とは限らないため、電子版の表紙であることを個別確認できない場合は、電子版表紙として断定していません。画像URLを登録・編集して正しい電子版表紙に差し替えられます。

参考書追加時は、出版社または電子書店が公開する電子版表紙画像URLと商品ページURLを入力してください。画像の利用条件を確認して使用してください。

注意：学習データはこの端末のブラウザ内に保存されます。端末変更・ブラウザデータ消去に備えて定期的にバックアップしてください。タイマーは開始時刻から復帰時に経過時間を再計算しますが、OSによるバックグラウンド動作を保証するものではありません。
